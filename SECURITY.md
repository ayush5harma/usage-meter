# Security policy

Please do not report security vulnerabilities in public issues.

Use GitHub's [private vulnerability reporting form](https://github.com/ayush5harma/usage-meter/security/advisories/new) and include enough detail to reproduce and assess the issue safely. Avoid including OAuth tokens, Keychain exports, account data, or other credentials in the report.

The project accepts reports for the current default branch. Security fixes are coordinated privately and credited only with the reporter's permission.
